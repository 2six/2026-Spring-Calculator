# Java Calculator Project

Java 과제로 제작한 계산기 프로젝트

Step 1부터 3까지 점진적으로 기능을 확장하며 Java의 문법, 객체지향, Enum, 제네릭, 람다/스트림 을 직접 사용해봄.

## 개발 환경

- Java 17

## 프로젝트 단계

### STEP 1 - 기본적인 계산기

클래스 분리 없이 하나의 파일엣거 기본적인 사칙연산 계산기를 구현

#### 기능

- 0 이상의 정수 2개 입력
- 사칙연산 기호 (+, -, *, /) 입력
- switch 를 이용해 사칙연산 수행
- 입력 검증
    - 숫자가 아닌 값 또는 움수 입력시 재입력
    - 잘못된 연산자 입력 시 재입력
    - 0으로 나누는 경우 예외 상황 처리

### STEP 2 - 클래스를 적용한 계산기

계산 기능을 Calculator 클래스로 분리하고 연산 결과를 관리하는 기능을 추가

#### 추가된 기능

- App과 Calculator 역할 분리
- Calculator 클래스에서 연산 수행
- ArrayList 를 사용해 연산 결과 저장
- 저장된 결과 중 가장 먼저 저장된 값 삭제

### STEP 3 - Enum, 제네릭, 람다/스트림 활용

기존 계산기를 다양한 Java 문법을 적용해 확장

#### 추가된 기능

- Operatory Type Enum 을 사용하여 사칙연산 타입 관리
- 제네릭 <T extends Number> 를 통하여 여러 숫자 타입 처리
- 스트림과 람다를 사용하여 특정 기준값보다 큰 연산 결과 조회
